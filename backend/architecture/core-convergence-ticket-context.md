# P5：基础工单关联业务记录

工单创建现在可以附带当前账户的订单、独立订阅和余额账务记录编号。
订单详情、独立订阅列表和余额账目提供实际“提交工单”入口，只预填上下文，由用户填写
问题并明确提交。旧工单的关联保持 NULL；不从主题、当前套餐或用户当前
订阅猜测历史上下文。此批属于 P5 的一个小闭环，不代表 P2–P7 完成。

## 权威写入与权限

`experience.Tickets.Create` 仍是唯一创建应用能力，HTTP 和现有应用入口
复用它。`experiencestore.Tickets.CreateTicket` 在现有事务中检查每个显式
关联记录属于创建人，然后一起提交 Ticket、首条 TicketMessage 和附件。
失败时全部回滚。详情和列表返回持久记录，回复、状态变更不允许换绑。

关联仅为支持上下文，不授予记录访问权，不修改订单状态、支付事实、
余额或订阅，不触发退款或履约。缺失和他人记录使用相同错误，不提供
跨账户存在性探测。管理员通过普通创建入口也只能关联自己的记录；
管理员详情继续使用既有管理员工单权限，会员详情不扩大范围。

锁顺序先显式来源订单 SHARE，再账户 SHARE，再订阅/账目 SHARE；不在
等待来源订单时持有账户锁，避免反转现有财务路径的订单→账户顺序。
每次创建最多三次按主键及 owner 检查，不为上下文添加历史明细扫描。

## 前端草稿和明确提交

`TicketCenter` 显示真实关联，创建表单可输入三个可选正整数编号；空项
不发送。链接的 `new=1` 和编号只是草稿上下文，不发创建请求。非法、
重复 query 参数和浏览器无法精确表示的编号在提交前报错。

新上下文不覆盖已有创建草稿，也不切换有未发送回复的会话。界面解释
尚未应用上下文；用户明确点击新建时复用已有放弃回复确认。取消保留
原回复，确认后新建不会把旧回复发送到新会话。管理员不应用会员创建
链接。服务端所有权失败保留表单并展示错误。原附件、权限和导航契约
保持，由原测试加行为测试共同验证。

初始0058批次只在表单/链接中接受订阅编号；后续已补订阅列表快捷入口，
验证范围见下方2026-10-20增量。
客服机器人和外部客服渠道仍属插件能力，不在此批实现。

## 0058 迁移、恢复和回滚

0058 仅新增 Ticket 的三个可空标识字段。MySQL 正式迁移单次 ALTER；
SQLite 正式迁移逐列执行。兼容恢复在 SQLite AutoMigrate 前检查：

- 未记录 0058、部分字段存在且均无历史关联时，可补齐并记录；记录
  失败后重复启动可核对补齐，不生成假收据。
- 完整字段可重复执行，旧 Ticket、首消息和 NULL 上下文不改写。
- 已记录 0058 但任何字段丢失，或未记录的部分字段已含上下文，启动
  拒绝并要求恢复证据。不能用自动补 NULL 假称历史关联完整。

down 为无损 SELECT，不删除关联、工单或迁移收据。旧二进制的严格迁移
清单可能拒绝 0058；应提供兼容修复版本或在隔离恢复副本中验证，不承诺
旧程序可直接降级，也不能删除收据强行启动。回滚代码前停止写入并备份，
保留新增字段及业务历史。没有执行生产迁移。

## 验证范围

双库实际执行正式 DDL、新库、旧 NULL 记录、部分字段、记录中断、重复
恢复和历史字段丢失。实际应用/HTTP 用真实余额支付构造订单与订阅，
覆盖三个本人关联、各类他人/缺失/零值/混合关联拒绝、管理员普通入口、
详情权限、旧工单和首消息失败回滚；支付和余额事实不变。

MySQL 另用并发持锁验证等待订单不占账户：初稿 user-first overlay 实际
返回 NOWAIT 3572，正确锁序通过。前端行为测试覆盖预填、非法编号、
dirty create/reply、取消/接受确认、真实订单/余额入口和错误恢复。
精确命令、失败与全量检查结果见本批 validation 收据。真实浏览器的
自动续费验收属于另一批，不把组件测试当作浏览器或生产验收。

## 每份订阅独立进入工单（2026-10-20增量）

账户订阅列表每行现在提供“就此订阅提交工单”，仅携带该行的
`new=1&subscription_id`，不使用当前管理链接的选中订阅、用户编号或凭据。
到期/已结束记录同样可求助；非正安全整数编号不显示入口。点击只打开
已有TicketCenter草稿，仍须填写并明确提交，继续复用其所有权、脏草稿
保护和服务端事务，不发起财务或凭据写入。没有迁移、权限或业务政策变更。

实际组件/RouterView行为测试逐行点击两份订阅，即使当前管理的是另一份，
进入的表单仍只预填点击行的订阅；不创建工单、轮换/吊销或重读凭据。
另覆盖历史生命周期和编号边界。22项窄测通过，原六排除全套1112通过、
保留原8skip/2文件skip，typecheck/build通过；未新增skip或排除项。
未另行运行此入口的Chromium、后端或MySQL验收；原退款浏览器收据不
冒充这个新增入口的浏览器证据。见[精确收据](validation/2026-10-20-subscription-ticket-shortcut.json)。
