# ZBoard

[English](README.md) | [简体中文](README.zh-CN.md)

**一站式机场面板管理平台。**

ZBoard 将 VPS 基础设施、协议节点、订阅交付、用户套餐、订单、流量结算和日常运维整合到同一套系统中。

它不只是一个订阅面板，而是覆盖机场运营完整生命周期的平台：从 VPS 接入、协议服务管理，到套餐销售、订阅交付、流量统计和运维审计。

> ZBoard 当前仍在开发中，当前开发基线为 `v0.0.1`，首个公开版本计划为 `v0.1.0`。

## 完整运营链路

```text
VPS 基础设施
      ↓
协议服务
      ↓
节点组
      ↓
套餐 / SKU
      ↓
订单 / 订阅
      ↓
客户端配置交付
      ↓
流量结算
```

## 核心能力

### 基础设施管理

- 管理 VPS 资产、SSH 凭证、主机信任和节点状态。
- 安装、校验、升级和回滚 Zero 运行组件。
- 发布节点配置并跟踪运行结果。

### 协议服务

- 支持 VLESS、VMess、Shadowsocks、Trojan、Hysteria2。
- 协议服务与物理节点分离管理。
- 支持服务复用、迁移和节点组管理。

### 订阅交付

- 为 ZNet Sink、Clash/Mihomo、sing-box 生成客户端配置。
- 管理模板、规则、策略组、出站目标和节点过滤。
- 交付前校验配置。
- 支持订阅凭证轮换和撤销。

### 商业运营

- 管理用户、套餐、SKU、订单、订阅、续费和流量额度。
- 保存订单和权益快照。
- 提供用户端订阅和用量查询能力。

### 流量与运维

- 接收节点流量事件并关联订阅。
- 支持流量结算和数据核对。
- 提供任务、日志、审计、备份、升级和回滚能力。

## 资源模型

```text
节点资产 → 协议服务 → 节点组 → 套餐 / SKU → 订单 → 订阅
```

ZBoard 将基础设施资源和商业资源分离，使节点和服务可以持续演进，而不会影响用户已经购买的权益。

## 为什么选择 ZBoard

传统机场面板通常关注订阅和商品，而 VPS 管理、协议生命周期和运维流程仍依赖外部工具。

ZBoard 将基础设施、服务交付和商业运营统一管理：

| 传统方式 | ZBoard |
| --- | --- |
| 节点和商品分离管理 | 基础设施与业务资源关联 |
| 订阅直接绑定服务器 | 使用可复用服务和节点组 |
| 输出固定订阅 | 生成并校验客户端配置 |
| 独立维护流量数字 | 将运行事件关联到订阅 |

## 技术基础

| 组件 | 技术 |
| --- | --- |

| 数据 | MySQL 8、Redis |
| 节点运行时 | Zero |
| 接口 | RESTful `/api/v1`、OpenAPI |
