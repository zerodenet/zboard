# 后台与用户中心 UI 排查记录

本轮只修改本地源码并验收，不构建、不发布、不部署。

## 覆盖范围

由实际路由提取的 32 个后台页面和 11 个用户中心页面均进入规范检查；共享表格、状态、文字、卡片、提示、字体层同步扫描。代码扫描覆盖不等于逐页完成所有业务状态的浏览器验收。

| 区域 | 本轮统一处理 |
| --- | --- |
| 共享呈现 | 正文和实体名称使用可读字号；统一 400/500/600 字重；无描述不占空行；无徽标不预留徽标空间；普通指标图标保持中性；缺失时间仅显示短横线 |
| 后台资源列表 | 证书、DNS、供应商、订单的长文本仅在实际截断时补充提示；供应商名称直接编辑；能力、格式和计费方式使用普通文本 |
| 节点与任务 | 去除资产状态的同义说明；主机资源区域去除读取机制段落；执行中、待核验、取消和失败保持不同语义；核验表单复用标准按钮 |
| 邮件、注册和规则集 | 移除默认展示的内部流程图与重复说明；使用说明及变量放到需要时展开的位置；保留格式限制、错误和凭据后果 |
| 用户概览 | 套餐名称和订单号直达对应管理页面；合并重复订阅身份列；金额右对齐；首次加载使用骨架，刷新保留数据；取消重复失败徽标和快捷入口说明 |
| 用户账户与公告 | 密码确认错误贴近字段；提交时有忙碌状态；公告不重复展示同义状态；空余额、实际金额和币种保留各自含义 |
| 规范防回退 | 路由驱动的后台和用户中心模板检查；全页面和组件的状态格/操作分离、重复原生标题、共享字体检查 |

## 验证边界

- 浏览器使用真实 `AdminLayout` 和 `AccountLayout`，数据为隔离的本地测试夹具，适配器拒绝所有非 GET 请求。
- 用户概览检查 1920、1440、1280、1024、768、390px 六种宽度；后台供应商、用户余额和公告检查桌面及手机布局，覆盖深浅色。
- 实测手机导航、供应商名称直接编辑、关闭后返回名称焦点、公告展开不同内容；检查零余额与流水金额、完整错误无重复标题、普通属性无状态徽标。
- 生产数据、付款、发送、删除和权限均未操作；业务 API 和账务规则未修改。
- 相关组件、用户中心、后台管理入口、登录后草稿恢复和权限隔离测试以及 `vue-tsc --noEmit` 的实际结果见本地验收日志。每页的全部真实数据状态仍需在后续获准发布后的生产验收中核对，不能由这些静态规则推定。
